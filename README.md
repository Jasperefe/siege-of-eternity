# Siege of Eternity

A 3D medieval-fantasy wave-survival action game that runs in the browser (Three.js).

**Play:** https://jasperefe.github.io/siege-of-eternity/

Hold the castle against endless waves of goblins, undead, demons and dragons. Combo, parry, dodge, and pick an upgrade card after every wave.

Controls: WASD to move, left click / J to attack, right click / K to block (parry), Space to dodge, Q for Wrath. On phones, an on-screen joystick and buttons.

Art: Quaternius, KayKit (Kay Lousberg) and Kenney (all CC0). Sky: Poly Haven (CC0).
